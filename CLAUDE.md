# Cours POO Java — FSM Monastir, GLSI 2

Diapositives présentées en amphi (React + Vite, Vercel). Langue : français.

- Contenu : `src/course/ch1.ts`, `ch2.ts`, `ch3.ts` (données) ; rendu : `src/course/ui.tsx` ; navigation : `src/App.tsx` ; styles : `src/index.css`.
- Dans les textes : `**gras**`, `` `code` ``, `*italique*`.
- Ancienne version animée : commit `ede8d45`.

## Règles

- Aucune animation ni transition (garder la règle CSS globale).
- Une seule diapo sur l'IA.
- Une idée par diapo, phrases courtes, mots-clés en gras.
- Le fond suit les PDF de l'enseignante ; ne rien inventer.
- Tout code Java montré doit compiler (vérifier avec `javac`).
- Rien ne doit déborder d'une diapo 1920×1080 ; vérifier aussi le PDF et le mobile.
- Garder les touches ← → S O F (+ N pour les notes), l'URL `#numéro` et le PDF.
- Pas de nouvelle dépendance npm sans demander.
- `npm run build` doit passer après chaque modification.

# Cours POO Java — version simplifiée

Diapositives statiques (sans animation), mots-clés en **gras**, IA réduite à une seule diapo.

## Où modifier le contenu

| Fichier | Contenu |
|---|---|
| `src/course/ch1.ts` | Accueil + Chapitre 1 (Introduction au langage Java) |
| `src/course/ch2.ts` | Chapitre 2 (Classes et objets) |
| `src/course/ch3.ts` | Chapitre 3 (Héritage, classes abstraites, interfaces) |
| `src/course/ch4.ts` | Chapitre 4 (Les exceptions) |
| `src/course/ch5.ts` | Chapitre 5 (Collections et génériques) |
| `src/course/slides.ts` | Ordre des chapitres |

Dans les textes : `**mot**` = gras, `` `code` `` = police code, `*mot*` = italique.

Types de blocs : `p` (paragraphe), `list`, `code` (+ `output`), `table`, `box` (`retenir` / `attention` / `info`),
`cols` (deux colonnes), `flow` (A → B → C), `exercise` (solution cachée, bouton ou touche **S**), `memory` (schéma pile / tas), `quiz` (options cliquables, correction au clic ou touche **S**).
Option `highlight: [n, …]` sur un bloc `code` pour surligner des lignes.

## Raccourcis en cours

← → : diapo précédente / suivante · **S** : afficher la solution · **O** : plan · **N** : notes enseignant (`src/course/notes.ts`) · **F** : plein écran · bouton **PDF** : imprimer tout le cours (solutions incluses).

L'URL garde la position : `…/#25` ouvre la diapo 25.
